# Local-only Experiment Files

Files placed in this directory are intentionally excluded from Git.

Except for this README, files here will **not** be committed to GitHub, included in a normal repository submission, or recoverable from the repository if your local copy is lost.

Do **not** place any of the following here:

- required source code;
- benchmark instances;
- results required by a checkpoint;
- final experimental data used to support your conclusions; or
- any file another person would need to reproduce your important results.

Use this directory only for disposable or machine-local intermediate files.
